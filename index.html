      文字识别 · OCR

      默认本机识别，不上传截图。复杂版面可以改用云端 OCR；选中之后，选区图片才会发给该服务商。

      云端 OCR 会将你选区的截图上传到所选端点。仅使用信任的服务；密钥单独存入系统凭据库。JSON 网关使用固定模板，不执行 JavaScript。

      快捷键

      划词翻译和截图识别是两个主要操作。占用时会提示，并可一键更换。

      默认仅启用划词 Alt+D、截图识别 Alt+S（Mac 上 Alt 对应 Option）；两项均可修改或清空。其他操作保留菜单入口，也可在高级快捷键中自行绑定。录制后松开按键即保存。Windows 上这两个默认组合在 EchoLingo 运行时优先；macOS 不能强制覆盖其他应用已注册的快捷键，占用时请更换。其他程序退出后，未生效的快捷键会自动重试。

      偏好与历史

      历史仅保存在本机，默认保留最近 20 条。

      Windows 取词

      选中文字后，按取词快捷键即可自动翻译。

      复制兼容会在原应用中模拟一次 Ctrl+C，再显示翻译框。部分代码编辑器未选词时会复制整行，可切换到严格识别。取词会尝试恢复原剪贴板，无法安全恢复时会提示。

      系统权限

      首次使用划词或截图时，请开启对应权限；直接输入和粘贴无需授权。

      首次使用：如何授权
      1. 点对应权限的「请求授权」或「验证录屏授权」，按 macOS 提示操作；没有弹窗时，可点「系统设置 ↗」。
      2. 在「隐私与安全（性）」中，给 EchoLingo 打开对应开关。截图权限也可能名为「录屏与系统录音」或「屏幕与系统音频录制」。
      3. 列表里没有 EchoLingo 时，点「+」添加应用目录中的 EchoLingo.app。
      4. 系统要求时退出后重新打开应用，回到这里点「刷新状态」，再重试快捷键。

      权限与诊断

      遇到取词或 OCR 问题时，可检查系统、权限和快捷键状态。
