反馈问题或建议
  1. 01

    选择对应版本

    选择对应系统的安装包。Windows 运行安装程序，Mac 打开 DMG 后拖入“应用程序”。

  2. 02

    准备权限与服务

    在应用设置中检查所需权限，并选择本机、系统或自定义服务。云服务需自行配置账号与凭据。

  3. 03

    让文字给出回应

    选中文字按 Alt + D；图片文字按 Alt + S 左键框选。Mac 使用 Option，可在设置中改键。

“无感翻译”是自动监听屏幕吗？+

由你用快捷键主动触发。选词翻译先取得当前选区，再展示浮窗；区域 OCR 由你手动框选。应用不会在后台持续读取屏幕或轮询剪贴板。

一定需要 API Key 或联网吗？+

Windows 中英离线包无需 API Key；macOS 系统翻译要求 macOS 26+ 和事先准备好的语言模型。自定义云端翻译或云端 OCR 通常需要联网及对应服务凭据，费用由所选服务商决定。

翻译与 OCR 都能接入自己的服务吗？+

可以。翻译支持 OpenAI 兼容接口的端点、模型和提示词，以及 DeepL、LibreTranslate 等协议。OCR 可以分别配置支持的云端 OCR、兼容视觉模型或自定义 JSON 网关。具体协议、鉴权与支持范围以所用预览版本为准；官网演示不连接你的服务，也不收集密钥。

如何下载和更新内测版？+

点击上方对应系统的下载按钮，也可以前往 GitHub 发布页查看版本。升级前先从托盘或菜单栏完整退出旧版，再安装或替换新版。 Mac 首次打开可参考安装说明。
