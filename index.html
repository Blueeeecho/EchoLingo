01

四件平时用得上的事。Four things it actually does.

选中文字、框选识字、本机中英互译，或接上你自己的服务。按需出现，用完即走。Select words, read a region, translate Chinese and English on the device, or connect a service of your own. It shows up when you call it.

Alt + D

选词快捷翻译Selection hotkey

在原应用中选中文字，按 Alt + D。原文自动填入浮窗并翻译。没有选中文字时，空按可以直接输入。Select text in the app you are already using, then press Alt + D. EchoLingo fills the popup and translates it. Press the shortcut with nothing selected, and you can type instead.

Mac 上 Alt 对应 Option。快捷键可在设置中修改。Enter 翻译，Shift + Enter 换行。On a Mac, Alt is Option. Shortcuts can be changed in Settings. Enter translates, and Shift + Enter inserts a line break.

Alt + S

无感 OCRSeamless OCR

按 Alt + S，用鼠标左键拖动框选。松开后自动识字、填入原文并翻译。Esc 随时取消框选。Press Alt + S and drag with the left mouse button. When you release, EchoLingo reads the text, fills it in, and translates it. Esc cancels the selection.

默认本机 OCR。框选时桌面保持实时可见。只有你改选云端 OCR，图片才会上传。Local OCR is the default, and the desktop stays visible while you drag. A picture is uploaded only if you explicitly choose a cloud OCR service.

WindowsWindows

中英离线翻译Offline Chinese–English

Windows 安装包内置中英离线翻译，无需 API Key。文本由本机模型处理，不会自动改走云端。The Windows installer includes offline Chinese–English translation. No API key: an on-device model handles the text, and it does not silently switch to a cloud service.

macOS 上的系统翻译是另一项能力，需要 macOS 26+ 和你事先准备好的语言模型。On a Mac, system translation is separate. It needs macOS 26 or later and a language model you prepare first.

API

自定义翻译服务Custom translation services

翻译可配置 OpenAI 兼容接口的端点、模型与提示词，以及 DeepL、LibreTranslate。OCR 可另选云端 OCR、兼容视觉模型或自定义 JSON 网关。Translation can use an OpenAI-compatible endpoint, model, and prompt, or DeepL and LibreTranslate. OCR can use a supported cloud service, a compatible vision model, or a custom JSON gateway.

翻译与 OCR 分别配置。密钥保存在系统凭据库，不会写入历史。Translation and OCR are configured separately. Keys stay in the system credential store and are not written into history.

顺手的小工具：按 F1 截取可见窗口或拖选区域，再做标注、裁剪、复制或保存。它不替代翻译与 OCR，也不调用云服务。A handy extra: press F1 to capture a visible window or drag a region, then annotate, crop, copy, or save. It stays separate from translation and OCR and does not call cloud services.

只想留一张图？按 F1，悬停看轮廓，点击选窗口或拖动框选；Esc 取消。部分键盘需配合 Fn，也可在设置中改键。Just need a picture? Press F1, hover for an outline, then click a window or drag a region; Esc cancels. Some keyboards need Fn, or you can change the shortcut in Settings.

“无感翻译”是自动监听屏幕吗？Does seamless translation watch the screen on its own?+

由你用快捷键主动触发。选词翻译先取得当前选区，再展示浮窗；区域 OCR 由你手动框选。应用不会在后台持续读取屏幕或轮询剪贴板。You start it with a shortcut. Selection translation reads the current selection, then shows the popup. Region OCR uses a region you draw. The app does not keep reading the screen in the background, and it does not poll the clipboard.

一定需要 API Key 或联网吗？Do I need an API key or a network connection?+

Windows 中英离线包无需 API Key；macOS 系统翻译要求 macOS 26+ 和事先准备好的语言模型。自定义云端翻译或云端 OCR 通常需要联网及对应服务凭据，费用由所选服务商决定。The Windows offline Chinese–English package does not need an API key. macOS system translation needs macOS 26 or later and a language model you prepare beforehand. Custom cloud translation or cloud OCR usually needs a connection and credentials for that service. The provider sets the fees.

翻译与 OCR 都能接入自己的服务吗？Can both translation and OCR use my own service?+

可以。翻译支持 OpenAI 兼容接口的端点、模型和提示词，以及 DeepL、LibreTranslate 等协议。OCR 可以分别配置支持的云端 OCR、兼容视觉模型或自定义 JSON 网关。具体协议、鉴权与支持范围以所用预览版本为准；官网演示不连接你的服务，也不收集密钥。Yes. Translation supports an OpenAI-compatible endpoint, model, and prompt, plus DeepL and LibreTranslate. OCR can be configured separately with a supported cloud OCR service, a compatible vision model, or a custom JSON gateway. Protocols, authentication, and what a given preview supports are described with that version. This website demo does not connect to your service and does not collect keys.

F1 截图与 Alt + S 识字有什么区别？How is F1 capture different from Alt + S OCR?+

Alt + S 用于识字与翻译；F1 只截取当时可见的画面，进入独立编辑器，不读取被遮挡的窗口内容，也不调用 OCR、翻译或上传服务。可画矩形、箭头、文字、马赛克或实心遮挡，裁剪、撤销与重做；也能打开本地 PNG / JPEG。复制的是合并后的原生图片，保存为 PNG；默认保存位置为桌面，可自行调整。同名自动编号，不覆盖已有文件，也不会自动保存。敏感内容建议用实心遮挡，马赛克不保证不可推断。Alt + S reads and translates text. F1 captures only what is currently visible and opens a separate editor; it does not recover covered window content or call OCR, translation, or upload services. Add rectangles, arrows, text, pixel mosaics, or solid redaction; crop, undo, and redo, or open a local PNG/JPEG. Copy the flattened native image or save a PNG. The default folder is Desktop and can be changed. Name collisions get a numbered suffix—no overwrite or automatic save. Use solid redaction for sensitive content; mosaics do not guarantee it cannot be inferred.
