03 / SETTINGS

翻译服务

同时启用多个服务，对照不同的表达。

只会将你主动翻译的文字发送给已启用的 API 服务。密钥不会写入历史记录。

文字识别 · OCR

默认本机识别，也可连接自己的视觉模型或 OCR 网关。

云端 OCR 会将你选区的截图上传到所选端点。仅使用信任的服务；密钥单独存入系统凭据库。JSON 网关使用固定模板，不执行 JavaScript。

快捷键

在任意应用中唤起 EchoLingo。

格式示例：Alt+D、Ctrl+Shift+T、Command+Shift+T。留空可禁用该操作的快捷键。若被系统或其他应用占用，会显示注册失败提示。

偏好与隐私

安静工作，只保留你需要的。

截图只用于你主动选择的 OCR 操作。默认本机识别；选择云端 OCR 后会上传截图到选定端点。翻译文字会发送给已启用的翻译服务，请谨慎处理敏感内容。

联网的语音服务可能接收朗读文本；朗读按钮会在系统支持语音合成时显示。

权限与诊断

检查系统、截图权限、OCR 能力和快捷键状态。

macOS 的截图需要屏幕录制权限，划词可能需要辅助功能权限。Windows 的受保护窗口可能无法读取选中文字。
