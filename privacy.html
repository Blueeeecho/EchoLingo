隐私说明

更新于 2026 年 10 月 31 日 · 适用于当前预览阶段的功能与官网

This note is written in Chinese. The homepage summarizes the same boundaries in English: local OCR by default, no telemetry, keys kept in the system credential store, and history stored on this device.

回声译以你主动触发的桌面翻译和区域 OCR 为核心。应用、你选择的服务商与本官网各自处理的数据不同，下面逐项说明。

你主动触发，应用才获取内容

选词翻译由快捷键或明确操作触发，获取当前选择的文字；区域 OCR 由你手动框选。应用不持续读取屏幕，不在后台轮询剪贴板，也不静默替换源应用中的文字。

部分应用的选区获取可能使用受控复制及剪贴板恢复。不同应用、并发复制等边界仍在预览验证中，请以对应版本说明为准。macOS 权限在设置中由你明确操作，快捷键不反复申请权限。

本机 OCR 与云端 OCR

默认使用操作系统的本机 OCR。截图仅作为本机临时文件供识别使用，处理后删除。

只有你明确选择云端 OCR 时，框选图片才会发送给所选 OCR 服务。应用不会在本机识别失败后静默改用云端上传。服务商如何保存或使用图片，请查看其隐私条款。

翻译内容会发送到哪里

使用 Windows 中英离线翻译包时，文本在本机模型中处理。使用 macOS 系统翻译时，应用调用已准备好的系统语言模型；支持范围与系统版本有关，语言模型准备由你在设置中明确操作。

选择云端翻译或自定义 API 时，原文及完成请求所需的设置会发送到你配置的服务端点。即使 OCR 在本机完成，随后进行云翻译时，识别出的文字仍会发送给所选翻译服务。

第三方服务的账户、费用、数据保存和模型使用规则由其提供者决定。应用不会在服务失败后静默切换到另一个云服务。

密钥与本地记录

翻译与 OCR 密钥保存在操作系统的凭据库中。配置文件、翻译历史和应用日志不应包含密钥明文。运行时只在当前进程内按服务范围复用已读取凭据，系统仍可能在首次实际使用时要求认证。

翻译历史默认在本机保存最近 20 条，可设置为 1–100 条或手动清除；收藏也受本地历史上限约束。应用设置与窗口宽度偏好保存在本机。应用不提供历史云同步。

遥测与官网

应用不加入使用遥测。本官网没有自行添加访问统计脚本、广告、账户、追踪 Cookie 或表单，不收集 API Key。页面的互动示意使用固定样例，不访问你的屏幕、选区、剪贴板或翻译服务。

下载区从 GitHub 公开 API 读取已发布安装包的下载次数，不统计本页浏览或点击，不代表独立用户数。请求不附带账户凭据或当前页面的 Referer 地址；GitHub 仍会收到网站来源（Origin）和请求所需的网络信息（如 IP 地址）。浏览器本地仅缓存汇总下载量和同步时间，以减少请求；缓存 15 分钟内直接复用，联网失败时仅显示 7 天内的缓存并标明未更新。

官网托管在 GitHub Pages。GitHub 表明，访问 Pages 网站时会为安全目的记录访客 IP 地址；这属于托管服务的处理。可阅读 GitHub Pages 数据收集说明和 GitHub 隐私声明。

反馈与更新

可以通过 GitHub Issues反馈问题。Issues 是公开区域，提交时请隐去密钥、个人信息与不希望公开的原文或截图。功能与数据处理方式有实质变化时，本说明会随之更新。
