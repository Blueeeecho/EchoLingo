# 个性化需求与版本计划

## 0.1 初版重点
- 全局快捷键选文翻译、输入翻译、剪贴板翻译。
- 截图本机 OCR、截图翻译、静默 OCR 到剪贴板。
- 多翻译服务配置，OpenAI 兼容 / DeepL / LibreTranslate。
- 源/目标语言、可编辑系统提示词、系统凭据库密钥。
- 历史、收藏、搜索、删除、深浅主题、置顶与托盘。
- 普通翻译请求可停止；编辑/清空/隐藏后旧任务失效，不再写历史。

## 待实机验证
- Windows 原生交互与混合 DPI、多显示器。
- macOS 辅助功能/录屏权限，跨空间窗口显示。
- 性能：安装包体积、空闲内存、冷启动、截图 OCR 延迟，必须实测后再写数字。

## 后续候选功能（尚未承诺全部实现）
- 学术论文翻译：公式、引用、专业术语、PDF 断行优化。
- 个人术语库、提示词预设、润色/解释/总结模式。
- 自定义导入导出与快捷键预设。
- 流式输出与服务结果逐项显示。
- 原图覆盖翻译、连续 OCR、图片文件 OCR、二维码。
- 词典释义、音标、原生 TTS、跨服务对照细节。
- 明确权限边界的插件协议；不直接执行未经审查的 Bob 插件。
- 开机启动、代码签名、自动更新、商店发布。

## 添加需求的格式
- 使用场景：在哪个应用、什么内容、操作频率。
- 期望操作：快捷键或按钮。
- 期望结果：显示/复制/朗读/保存到哪里。
- 隐私要求：能否联网、能否保存原文。
- 优先级：必须 / 希望 / 可延后。
- 验收例子：给一段输入和预期行为。
