# macOS 安装

1. 下载 Apple 芯片版 DMG，打开后将 EchoLingo 拖入“应用程序”。
2. 从“应用程序”启动 EchoLingo，图标会出现在菜单栏。
3. 在回声译设置中按需开启“辅助功能”和“屏幕录制”，然后使用 Option+D 取词、Option+S 框选识字。

取词翻译需要“辅助功能”权限，截图 OCR 需要“屏幕录制”权限，两项需分别授权。缺少辅助功能时，翻译框会显示授权提示，可点击“打开系统设置”前往对应页面。

在新 Mac 上安装后，请在回声译设置中确认所需权限显示为已授权。如果系统开关已开启，应用仍显示未授权，请核对条目对应的是“应用程序”中的这份 EchoLingo；必要时移除旧条目并重新添加当前应用，退出菜单栏实例后重新打开、刷新状态。

当前提供预览安装包。首次打开若被 macOS 拦截，请先确认文件来自本项目的 [GitHub 发布页](https://github.com/Blueeeecho/EchoLingo/releases/tag/0.1.0-beta.2.1)，再打开“系统设置 → 隐私与安全性”，在相应提示处选择“仍要打开”，按系统要求确认。

Apple 系统翻译需要 macOS 26+ 及相应已安装的语言资源；也可以在回声译设置中配置翻译服务。升级前先从菜单栏完整退出旧版，再替换应用。若权限尚未生效，按设置页指引核对安装后的这一个 EchoLingo。
