# 自动中英互译：简化的输入处理

本规则只用于源语言和目标语言均为“自动”的中英互译模式，Mac、Windows 和所选翻译服务共用同一入口，不再用通用语言识别器把文件名判成印尼语、把中英说明判成土耳其语。

1. 完整文件名、路径、URL、型号标识符或纯数字符号，没有需要翻译的正文：直接显示“原文（无需翻译）”。原字节、空白和换行不变，不调用语言识别、密钥读取、翻译服务或语言包下载。
2. 含汉字正文：根据已有简繁字形提示选择中文→英文。纯英文正文：英文→简体中文。原文整段交给所选服务一次，不分片，不删除英文或符号。
3. 没有汉字、但含其他语言字母的正文：提示手动选择语言，不猜一个其他语言并引导下载语言包。

手动指定源语言或目标语言时继续原来的多语言翻译流程。自动中英模式中的汉字按中文处理，不能区分纯汉字日语等歧义；需要日语、韩语等语言时应手选。ASCII 拼写的真实外语也无法靠这套简单规则区分，应手选源语言。

这些规则替换早期的中文提示词表、12字门槛、技术日志分片和普通混合段落启发式，不继续叠加例外。对含正文的混合句，模型仍决定译文，不能保证其中所有型号符号都绝对原样；确定的完整结构输入才保证原样返回。服务真实错误仍显示错误，不会被伪装成成功的原文。

诊断 sourceResolution 区分 preservedStructure、bilingualMode、explicit 和 nativeOrFallback。保留原文分支仍走请求代次、取消、结果发布与历史控制，不能覆盖较新的结果。
