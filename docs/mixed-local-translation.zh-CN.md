# 自动翻译：只判断方向，不拦截内容

源语言和目标语言均为“自动”时，Mac、Windows 和所选翻译服务共用现有语言解析：识别为中文时译成英文，其他语言译成简体中文。

- 文件名、路径、URL、型号、数字和特殊符号都交给所选翻译服务，不再直接回显“原文（无需翻译）”。
- 语言检测失败或不确定不会阻止请求。先使用现有字符提示；仍无法判断时按英文→简体中文尝试。
- 日语假名、韩文字母以及有效的日语、韩语检测结果保留其源语言，不会仅因含汉字就改为中文→英文。
- 原文整段传给所选服务一次，不分片、不删字、不替换符号。服务决定译文；服务不支持该方向或执行失败时照常显示真实错误，不改用其他服务，也不伪装成成功。

手动选择的源语言或目标语言保持不变。语言识别和简单回退都可能误判短词、混合语言或纯汉字日语；遇到误判可以手动选择语言。自动方向的修改不代表修复 Apple 系统翻译会话故障。

请求代次、取消、进度发布与历史控制保持不变。历史记录中的原文保留标记仍能读取，但新请求不再进入该分支。
