# 本机混合技术日志翻译（0.2.1）

默认自动中英互译下，部分混合日志包含大量英文标识符、数字和符号，整体语言识别未必能正确反映其中中文说明的语言。0.2.1 对一小类明确的结构化技术日志增加保守处理：只把符合条件的中文说明片段交给本机翻译，明确使用中文→英文，再把结果插回原位置。

- 仅源语言和目标语言均为“自动”、本次所选服务全部是 Apple 系统翻译或 Windows 本机离线翻译时启用。手动语言选择及包含云服务的请求保持原处理。
- 当前结构门槛要求至少两个字段冒号、成对花括号或方括号，以及驼峰/下划线标识符，还须含“系统、注册、错误”等保守中文诊断用语。纯汉字本身不作为中文语言的充分证据；不满足门槛继续原语言识别。普通中英文章不启用此处理。它不是通用代码解析器。
- 英文、符号、编号、空格、换行不送入翻译；围栏代码、行内反引号代码、URL/邮件/路径及中英混合标识符保留。普通引号中的中文日志说明仍可翻译。
- 最多八个不同中文片段，重复片段复用；每段最多512字、原文最多20000 UTF-8字节。超过范围回到原翻译路径，不做半段预处理。
- 本机片段逐个执行，总期限45秒。取消停止后续片段；任何片段失败只返回错误，不发布半成品，也不自动重试或切换云端。原本的本机任务取消和剪贴板保护不变。
- 正确的中文语言包仍是必要条件。本处理只减少某些技术日志的整段自动语言误判，不保证所有混合文本都被识别或保证底层模型永不失败。
- 诊断中的 resolvedSource、resolvedTarget 记录实际中文→英文方向，mixedLocalFragments 只记录片段数量，不保存片段文字。

例如 `input (alt+KeyA)：系统注册失败：HotKey { key: KeyA, id: 65555 }` 仅翻译“系统注册失败”，保留其他内容。纯中文、纯英文或普通双语文章继续走原流程。

## 普通中英混合段落

普通段落不使用上述碎片处理。对于本机、自动中英互译且中文句法证据较强的中英混合段落，0.2.1 另对语言方向做保守稳定：至少12个汉字、两个不重叠的四字及以上汉字片段、两个不同中文句式提示（如“如果、需要、我们、已经”，简繁别名算同一个提示），并且没有假名、韩文或其他非拉丁字母脚本时，按中文简繁特征选择中文→英文。原文整段不变，不拆分，也不删除英文或符号。

仍执行一次本机识别；识别明确为日语/韩语时保留原方向。手动语言、包含云服务的请求、纯英文、姓名/短标签、同一提示重复，均不触发此稳定规则。这只是有界启发式，不是语言判定的绝对证明，也不保证消除 Apple `notInstalled`。

诊断 `sourceResolution` 使用固定枚举区分手选、常规识别、技术日志启发式及普通混合段落启发式；不记录识别文本。实际 `resolvedSource` / `resolvedTarget` 与翻译调用、历史及语言准备入口保持一致。
