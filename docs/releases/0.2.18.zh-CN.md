# EchoLingo 0.2.18 内测版

## 下载与升级

- **Windows 推荐免安装 ZIP**：`EchoLingo_0.2.18_windows_x64-unpack.zip`。完整解压后打开 `Start-EchoLingo.cmd`，不要只取出其中一个 EXE。另提供安装版。
- **macOS Apple 芯片**：`EchoLingo_0.2.18_macos_arm64.dmg`。
- 升级前完整退出旧版，并核对发布附件中的 `SHA256SUMS.txt`。GitHub 自动生成的源码 ZIP 不是应用安装包。
- 旧版 0.2.17 及其发布说明保留。本版为内测预发布，不标记为稳定版 Latest。

## 本次打磨

- **设置不再堆成一长页**：按常规、翻译服务、识别与截图、快捷键、权限与诊断、关于与更新分类；改善布局与阅读层级，保留已有服务配置入口及平台差异。
- **长文本计数更准确**：输入长度按 Unicode 码点计数，避免把一个非基本平面字符按两个 UTF-16 单元计入上限。仍保留输入长度限制。
- **首次翻译更容易排查**：增加主动开启的首次派发诊断，用于区分捕获、输入交付与翻译请求阶段；不以增加诊断宣称首次失败问题已在所有机器修复。
- **损坏数据不再默默覆盖**：保护损坏的本地设置、历史文件，提供恢复状态提示。分享诊断前移除可识别的本机路径信息；仍建议发送前检查内容。
- **内存优化先有可信基线**：加入手动启用的 Mac/Windows 进程集合采样工具与回归矩阵，区分主进程、可归属的子进程、离线引擎以及共享内存口径。本次没有默认启用离线引擎或隐藏 WebView 的自动卸载，也不宣称尚未实测的内存降幅。

## 运行要求与数据

Windows 10 1809+ / Windows 11 x64，仍需要 Microsoft Edge WebView2 Runtime。启动器只检查环境，不自动下载安装或修改安全策略。缺少运行环境时请按提示使用 Microsoft 官方渠道。

免安装指应用文件无需安装向导。设置、历史及 WebView 数据仍位于当前 Windows 用户的 AppData，密钥仍在 Windows 凭据库中，不会随 ZIP 一起迁移；安装包不包含用户数据或凭据。

macOS 包面向 Apple 芯片、macOS 12+；Apple 系统翻译需要 macOS 26+。Windows 未商业签名；macOS 使用 ad hoc 签名且未 Apple 公证。

## 验证范围与已知边界

发布前须将双端构建、最终安装包版本及哈希、原生安装包启动验收绑定到同一源码提交；实际通过结果以本次发布附件中的验证记录为准。不能用之前版本的通过记录代替本版。

前端自动化主要验证设置分类与导航、输入计数、诊断开关、损坏数据保护等变化；合成 UI/IPC 或静态检查不能替代真实原生翻译、用户电脑权限、Codex/聊天软件选区、物理多屏与混合 DPI 验收。首次派发诊断用于缩小问题范围，不等同于所有首次失败已解决。

进程采样单元测试不等于 Mac/Windows 上的整机实测。未能可靠归属的 WebKit/XPC helper 必须记为缺项，RSS 相加也不是独占物理内存；内存是否下降须在相同机器、相同 Release 构建条件下另行测量。
