# EchoLingo 0.2.9 内测版

- 截图编辑采用单一持续工具栏，减少工具切换时的位置变化；固定截图生成仅显示图片的独立贴图窗口。
- OCR 使用容量为一的独立执行域，隔离截图识别任务并加强取消、过期请求及资源释放边界。
- macOS 取词加强只读选区恢复：仅在公开选区、所属窗口与焦点等条件均通过严格检查时采用结果；不以模拟复制兜底。不确定或失败时保留干净的手动输入入口。
- 修复鼠标拖动已建立后，DOM 指针取消及捕获丢失错误结束原生拖动的问题；补充中断、释放与过期操作回归。
- 保留安装包严格检查、失败证据及源码身份绑定，包括 macOS 自有许可确认和 Windows 安装包标记校验。

本版本使用当前源码重新构建 Windows 安装包和 macOS App/DMG，发布须通过完整回归及既有安装验收；不以历史安装包或诊断运行替代。本次发布清单与校验和绑定本次源码提交、验证运行和实际安装包字节。

内测版仍可能存在问题；原生编译、合成测试不等于所有设备和应用场景均已验证。macOS 签名、公证、权限及 Apple 翻译资源可用性以实际系统状态为准；不宣称新增公证或绕过系统权限。云翻译和 OCR 仅在用户自行配置启用后使用，相关服务费用由服务商收取。
