# EchoLingo 0.2.15 内测版

## 下载

- **Windows 推荐免安装 ZIP**：下载 `EchoLingo_0.2.15_windows_x64-unpack.zip`，完整解压后打开 `Start-EchoLingo.cmd`。保留 NSIS 安装版，适合希望使用安装流程的用户。
- **macOS Apple 芯片**：下载 `EchoLingo_0.2.15_macos_arm64.dmg`。
- 升级前完整退出旧版；请核对 `SHA256SUMS.txt`，不要把 GitHub 自动生成的源码 ZIP 当作应用。

## 本次变化

- 修复 Mac 窗口拖动缩放结束时可能回弹的问题：以原生窗口最终宽度完成同步，避免迟到的旧尺寸覆盖新尺寸。
- 改进 Codex 嵌套选区中的被动 AXButton 恢复；无法确认选区安全性时停止恢复，不主动点击控件，不放宽受保护内容限制。
- 新增复制回退的终止原因诊断，区分剪贴板变化、稳定状态和超时；保持原有复制及恢复逻辑。
- 翻译失败后保留经过脱敏的错误元数据，便于定位问题；不在该诊断中保存原文、译文或密钥。

## 运行要求与数据

Windows 10 1809+ / Windows 11 x64，仍需系统中的 Microsoft Edge WebView2 Runtime。启动器只检查运行环境，不自动下载或安装、不修改安全策略；缺失时请按提示前往 Microsoft 官方渠道安装。

免安装仅指应用文件无需运行安装向导。配置、历史与 WebView 数据仍保存在当前 Windows 用户的 AppData，密钥仍在 Windows 凭据库中，不会随 ZIP 搬走。ZIP 内不包含用户数据或凭据。

macOS 安装包面向 Apple 芯片、macOS 12+；Apple 系统翻译需要 macOS 26+。Windows 未商业签名，macOS 使用 ad hoc 签名且未 Apple 公证。旧版 0.2.14 及更早发布保留下载。

## 验证范围

本发布要求同一提交的双端全新构建及安装包结构、版本、应用字节检查。Mac 还要求从最终 DMG 提取的完整应用实际启动、设置窗口与 WebView 就绪、重复启动和重新打开、原生 Swift 自检及窗口缩放夹具通过；运行证据绑定同一源码提交、构建任务、DMG 和应用 SHA-256。Windows 保留最终 ZIP 的真实解压启动、设置 WebView、第二次启动转发、双向离线模型执行、内嵌捕获自检，以及实际设置快捷键和生成内容的原生焦点回归。
