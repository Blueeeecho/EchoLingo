# EchoLingo 0.2.11 内测版

- 调整 macOS 截图显示器切换与选区窗口交接，减少切换显示器时的定位和显示状态冲突。
- 调整贴图的点击与拖动判定，并将原生拖动绑定到当前鼠标按下操作，避免过期操作继续移动贴图。
- 改善截图保存与复制的独立结果处理：一项失败时保留另一项的成功结果，避免错误地将两项都报告为成功或失败。
- 改善标注绘制预览、选中后的尺寸调整及文字编辑交互。
- 为 macOS 取词增加有界、安全的停止原因诊断，不记录选中文字；取词现场问题仍未解决，不将诊断补充作为修复完成的证明。

本版本使用当前源码重新构建 Windows 安装包和 macOS App/DMG，发布须通过既有回归及安装验收。发布清单与校验和绑定本次源码提交、验证运行和实际安装包字节，不以旧版资产或历史诊断替代。

真实双屏与拖动现场尚未验证；合成测试不代表所有设备和应用场景均已验证。本次不修改 Apple 系统翻译功能，也不宣称已解决其资源或翻译可用性问题。macOS 签名、公证及权限要求以实际安装包和系统提示为准。
