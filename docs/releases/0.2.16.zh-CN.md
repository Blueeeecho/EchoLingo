# EchoLingo 0.2.16 内测版

## 下载

- **Windows 推荐免安装 ZIP**：下载 `EchoLingo_0.2.16_windows_x64-unpack.zip`，完整解压后打开 `Start-EchoLingo.cmd`。保留 NSIS 安装版，适合希望使用安装流程的用户。
- **macOS Apple 芯片**：下载 `EchoLingo_0.2.16_macos_arm64.dmg`。
- 升级前完整退出旧版；请核对 `SHA256SUMS.txt`，不要把 GitHub 自动生成的源码 ZIP 当作应用。

## 本次变化

- 翻译框关闭或隐藏后，下次打开恢复默认自动中英互译，不再沿用上次临时选择的语言。
- 在同一次可见会话中保留手动语言选择；重放历史记录后，关闭翻译框同样恢复默认。
- 处理迟到的窗口隐藏通知，避免旧会话覆盖新会话的语言选择。设置页面切换及置顶截图操作保持现有行为。

## 运行要求与数据

Windows 10 1809+ / Windows 11 x64，仍需系统中的 Microsoft Edge WebView2 Runtime。启动器只检查运行环境，不自动下载或安装、不修改安全策略；缺失时请按提示前往 Microsoft 官方渠道安装。

免安装仅指应用文件无需运行安装向导。配置、历史与 WebView 数据仍保存在当前 Windows 用户的 AppData，密钥仍在 Windows 凭据库中，不会随 ZIP 搬走。ZIP 内不包含用户数据或凭据。

macOS 安装包面向 Apple 芯片、macOS 12+；Apple 系统翻译需要 macOS 26+。Windows 未商业签名，macOS 使用 ad hoc 签名且未 Apple 公证。旧版 0.2.15 及更早发布保留下载。

## 验证范围

本发布要求同一提交的双端全新构建及安装包结构、版本、应用字节检查。Mac 还要求从最终 DMG 提取的完整应用实际启动、设置窗口与 WebView 就绪、重复启动和重新打开、原生 Swift 自检及窗口缩放夹具通过；运行证据绑定同一源码提交、构建任务、DMG 和应用 SHA-256。Windows 保留最终 ZIP 的真实解压启动、设置 WebView、第二次启动转发、双向离线模型执行、内嵌捕获自检，以及实际设置快捷键和生成内容的原生焦点回归。

前端合成 UI/IPC 回归覆盖关闭后重开、手动语言选择、历史重放和迟到事件；它不等于真实桌面翻译引擎验收。

以上为有界验收，不代表真实 Codex 聊天选区、用户电脑权限状态、物理多屏/混合 DPI、截图/OCR 全量现场验证或断网证明。Apple 系统翻译的策略自检不等于调用真实翻译引擎。用户现场问题仍需按具体复现结果判断。本版为内测预发布，不使用稳定版 Latest 标记。
