# EchoLingo 0.2.6 测试版

本次保留原始构建的 Windows x64 / macOS arm64 安装包，不重新编译、不覆盖旧版本。原始构建运行的总体结果仍为失败；macOS 初次检查被磁盘映像的许可确认阻止，另行对完全相同的 DMG 与原签名应用执行静态检查。Windows 初次检查遗漏了仓库已有的 Tauri NSIS 标记变换规则；独立检查仅按该完整标记与完整文件哈希证明原安装包身份，没有改写二进制。两项独立检查成功不改变原始运行的失败记录。

- macOS 选区源身份改为精确序列化，防止跨语言数字转换导致误判；QQ 多选回退策略收紧。
- 调整 Alt+S 悬停轮廓、文字排版与设置焦点样式。
- F1 截图编辑保留原始屏幕表面，工具栏限定在可用屏幕区域。

## 验证范围与限制

原生策略、桥接、浏览器和静态安装包检查通过，不等于在真实 Codex、飞书、QQ 中完成交互验收。尚未完成安装后运行验收、真实中文输入法候选窗、物理多屏与混合 DPI 验收；不能据此承诺所有现场问题均已消失。macOS 应用为 ad-hoc 签名，未公证。

`RELEASE-MANIFEST.json` 记录原始产物、源码与发布来源；两份平台 `CANDIDATE-MANIFEST` 保留原始字节及安装包/应用哈希；`REINSPECTION-MANIFEST.json` 与 `REINSPECTION-MANIFEST.Windows.json` 分别记录原构建与两平台再检查，明确未重建、未修改二进制。`SHA256SUMS.txt` 覆盖实际发布资产。Windows 对应离线引擎源码随附；仅复用经过固定哈希验证的引擎、模型与许可证，旧安装包的验收不转移给本版。
