# EchoLingo 0.2.3 内测版

本版聚焦截图中断后的恢复、翻译浮窗与设置弹层的交互，以及 Windows 快捷取词/截图响应。

## 本版改动

- Windows 区分窗口初始化/跨屏 DPI 通知与真实显示拓扑变化。前者按当前显示器元数据复核，后者仍安全取消；取消后清理原生输入会话，下一次截图可以重新开始。不会要求用户改系统缩放设置，也不承诺已经覆盖每一种显示硬件。
- 外部取词或截图带来新结果时，配置弹层暂时收起，不再挡住翻译；可通过恢复入口继续原草稿。未保存凭据仅保留于原内存表单，旧保存/确认回调不能抢占新的操作。
- Windows 截图改用独立 Rust 原生选区进程和 WinRT OCR，默认截图不再启动 PowerShell/CLR；划词的 UI Automation 与复制保护仍保留现有实现。旧截图路径仅可通过显式诊断开关选择，不会在原生失败后静默回退。同一 Windows CI 机器上，三轮交错对照当前轻量 PowerShell 启动器，首次截图请求到首个边框的中位数约 689→100 毫秒、完整选区就绪约 766→148 毫秒。这是生成测试窗口上的控制器计时，不是所有设备上的实际 Alt+S 端到端承诺，也不代表 Alt+D 已消除启动成本。在同一轮真实应用测试中，普通窗口/置顶模态窗口/安装后离线场景中指定截图流程的 Alt+S 到首个边框观测约为 164/190/288 毫秒；普通/模态数字来自显示变化取消后的恢复截图，并非进程首拍冷启动。它们仅是这次 CI 样本，包含轮询与身份验证开销，不是普遍时延保证。
- macOS 截图后端保持原有实现；本版的原生截图替换仅针对 Windows。
- Mac 在旁边空输入框取得焦点但正文存在唯一可验证选区时，增加同窗口与原始选区复核，避免过早拒绝。密码/受保护输入、窗口变化或验证失败仍拒绝，不额外放宽自动复制权限。
- 补充有界、仅数值的截图阶段与当前宿主会话诊断；测试覆盖显示变化取消、清理、下一次请求，以及配置草稿的恢复和过期回调隔离。

## 验收与使用说明

- Windows：`EchoLingo_0.2.3_windows_x64-setup.exe`；Apple 芯片 macOS：`EchoLingo_0.2.3_macos_arm64.dmg`。均从本版源码重新构建，不复用或覆盖 0.2.2 安装包。
- 更新前从托盘或菜单栏完整退出旧实例；macOS 辅助功能/屏幕录制权限应对应当前安装应用。
- 发布需通过标准双端构建、原生回归、真实桌面验收与安装后离线验证；默认路径必须在未设置后端环境变量时通过真实截图/OCR与会话恢复测试。具体结果见本次发布工作流与 RELEASE-MANIFEST.json。
- 默认保留划词和截图两项快捷键，仍可在设置中修改或清空；macOS 的 Alt 对应 Option。
- 无正式证书/公证；安装提示及系统权限配置请参阅仓库安装文档。

## 仍需真实设备反馈

不同显示器、DPI、源应用、系统权限及设备性能会影响行为。上层窗口与自家安装器初始页面测试已在同一 High 完整性级别运行，未执行该页面的安装操作；不绕过 UAC 安全桌面，也不宣称已覆盖跨权限窗口或所有物理多屏配置。Mac 首帧观感、物理窗口外沿手感及既有间歇剪贴板兼容性不能只凭自动化验收宣称全部根治。出现问题时请附复现步骤与诊断信息，避免附密钥或敏感原文。

曾在浏览器取词回归中观测到原剪贴板 Unicode 格式经 OLE 读取为空，而 HTML/RTF 保持一致。后续完整测试未再次复现；新增只读诊断与关闭诊断观察的独立验收用于区分问题，不等于已证明根因或保证所有第三方应用永不失败。具体最终验收结果以对应源码提交的工作流原始报告为准。
