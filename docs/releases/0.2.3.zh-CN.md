# EchoLingo 0.2.3 内测版

本版聚焦截图中断后的恢复、翻译浮窗与设置弹层的交互，以及 Windows 快捷取词/截图响应。

## 验收与使用说明

- Windows x64 与 Apple 芯片 macOS 均从本版源码重新构建；不复用或覆盖 0.2.2 安装包。
- 发布需通过标准双端构建、原生回归、真实桌面验收与安装后离线验证。具体结果见本次发布工作流与 RELEASE-MANIFEST.json。
- 默认保留划词和截图两项快捷键，仍可在设置中修改或清空；macOS 的 Alt 对应 Option。
- 无正式证书/公证；安装提示及系统权限配置请参阅仓库安装文档。

## 仍需真实设备反馈

不同显示器、DPI、源应用、系统权限及设备性能会影响行为。Mac 首帧观感、物理窗口外沿手感及既有间歇剪贴板兼容性不能只凭自动化验收宣称全部根治。出现问题时请附复现步骤与诊断信息，避免附密钥或敏感原文。
