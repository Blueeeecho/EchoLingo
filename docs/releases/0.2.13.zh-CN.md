# EchoLingo 0.2.13 内测版

- 简化自动翻译方向：不再因混合语言、短文本或检测置信度不足而提前阻止翻译请求。
- 手动指定目标语言但无法确定源语言时，使用明确的备用源语言继续请求，避免第二次检测失败再次阻断流程。
- Apple 系统翻译不再把源语言与目标语言相同的请求直接当成成功并返回原文；交由实际服务处理，服务拒绝或失败仍如实报告。

Windows x64 与 Apple 芯片 macOS 安装包由本次源码重新构建。验证范围为两平台共享语言路由测试、实际应用的相关请求生命周期测试及安装包静态检查。发布清单绑定源码提交、运行记录与实际安装包字节。

本次未重跑完整回归、安装后运行、截图、OCR 或视觉验收，不把历史结果声明为新安装包已通过上述检查。Windows 仅复用哈希核验且源码未变的离线引擎、语言模型、许可证和对应源码，不复用旧版应用。真实设备、真实服务及混合语言翻译质量仍需复测；本次不宣称修复其他取词、截图或多屏现场问题。

这是测试预发布版，不是稳定版。Windows 未商业签名；macOS 使用 ad hoc 签名，未经 Apple 公证。旧版本仍保留下载。安装前请核对 SHA256SUMS.txt 与 RELEASE-MANIFEST.json，并完整退出旧版应用。
