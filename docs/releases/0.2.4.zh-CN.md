# EchoLingo 0.2.4 内测版

本版新增独立的 F1 截图与本地图片编辑，并改进取词来源一致性、剪贴板格式保护、Windows 放大镜连续性，以及翻译浮窗的布局与展示顺序。

## 本版改动

- 新增独立 **F1** 截图入口：悬停显示可见窗口轮廓，点击选择窗口，拖动选择区域；窗口身份或边界变化时安全取消。捕获的是当时可见的屏幕区域，不恢复被遮挡内容。**Alt+S 无感 OCR 保持独立**，F1 不调用 OCR、翻译或云服务。
- 新增本地图片编辑：矩形、箭头、文字、像素马赛克、实心遮挡、裁剪、撤销与重做；也可打开 PNG / JPEG。复制合并后的原生剪贴板图片，保存为 PNG 文件；不附带编辑图层或源文件元数据。
- 默认保存到系统桌面，可另选目录；文件名根据截图时间生成，同名自动编号，不覆盖源文件或已有图片。不会自动保存。截图编辑器按需创建，不为未使用的入口额外创建启动窗口。
- Windows 复制兼容路径保留经原生检查确认的已知剪贴板存在性标记；未知或不可读取的格式仍安全拒绝，不以丢弃格式换取成功。诊断仅使用有界枚举与数值，不包含选文或剪贴板内容。
- Windows 原生截图放大镜在节流间隙保留上一帧，复用会话内采样资源，减少重复窗口状态更新；取消、结束和未就绪时仍隐藏。
- macOS 在请求入口固定来源窗口，后续始终核对原有 CG 或 AX 身份。受约束的焦点建立路径可尝试一次只读正选区恢复；权限、保护输入、来源变化和查询异常仍安全停止。复制次数、剪贴板所有权与恢复边界不放宽。
- 浮窗流式内容从当前顶部锚点向下增长，并预留滚动条宽度。macOS 显式展示前核对原生尺寸、WebView 视口和屏幕比例，避免旧布局被当作新展示的就绪状态；超时不伪装成成功。

## 验收与安装

- Windows：`EchoLingo_0.2.4_windows_x64-setup.exe`；Apple 芯片 macOS：`EchoLingo_0.2.4_macos_arm64.dmg`。
- 使用标准双端构建与发布流程；只有必需 CI 和发布验收通过，才发布同次运行验证过的安装包。发布后不重新构建或覆盖 0.2.3 资产。
- 新增取词来源、剪贴板标记、放大镜连续性、隐藏 WebView 视口及浏览器展示回归。Windows 发布验收使用已确认嵌入实际应用的原生截图子程序，要求完整连续性用例结果；不能仅凭步骤退出成功认定通过。F1 原生选择器、实际 NSIS 安装后的截图编辑流程与浏览器像素编辑各自保留独立验收，不用 mock IPC 代替原生功能。安装后必须验证窗口与区域截图、PNG/JPEG 打开、复制与保存、取消、不覆盖、零 OCR/服务调用及所有权清理，并核对完整应用字节身份；重复的安装前编辑器测试仅作诊断。
- 更新前从托盘或菜单栏完整退出旧实例。安装来源、对应源码、SHA-256 和验证工作流见本次发布的清单与校验文件。
- Windows 未商业签名；macOS 使用 ad hoc 签名，未经 Apple 公证。系统可能显示安装风险或要求重新授权。

## 验收范围

发布门槛保留核心功能、原生输入与取消、有效截图和编辑导出、剪贴板所有权、安装包身份及资源清理。放大镜的细粒度像素观测、运动密度、毫秒截止线和反复 A/B 性能比较只作质量诊断，不再单独阻止发布；原始未达标记录仍保留，不改写为通过，也不据此承诺所有设备的流畅度或时延。核心结果与质量诊断在新报告中明确分开，旧报告不会按新规则追溯标记通过。

## 验证边界

这是内测版，不是稳定版。生成窗口、纯策略和浏览器 mock 测试不能证明所有真实应用均可取词，也不能替代物理鼠标跟随、复杂剪贴板历史、连续操作和混合 DPI 多显示器验收。原生几何与 WebView 视口确认不等于操作系统合成器已绘制清晰首帧；真实设备的流畅度、首帧清晰度及兼容性仍需复测，不作普遍时延或成功率承诺。

截图编辑限制为 32 MiB 编码文件、3200 万像素和单边 16384 像素；原生捕获可能采用更严格限制。像素马赛克不保证敏感文字不可推断，敏感内容推荐使用实心遮挡。macOS 截图的生成元数据及取消策略测试不等于真实屏幕权限、文件对话框或多屏设备验收；实际安装环境仍须复测。
