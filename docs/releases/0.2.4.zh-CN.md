# EchoLingo 0.2.4 内测版

本版聚焦取词来源一致性、剪贴板格式保护、Windows 放大镜连续性，以及翻译浮窗的布局与展示顺序。

## 本版改动

- Windows 复制兼容路径保留经原生检查确认的已知剪贴板存在性标记；未知或不可读取的格式仍安全拒绝，不以丢弃格式换取成功。诊断仅使用有界枚举与数值，不包含选文或剪贴板内容。
- Windows 原生截图放大镜在节流间隙保留上一帧，复用会话内采样资源，减少重复窗口状态更新；取消、结束和未就绪时仍隐藏。
- macOS 在请求入口固定来源窗口，后续始终核对原有 CG 或 AX 身份。受约束的焦点建立路径可尝试一次只读正选区恢复；权限、保护输入、来源变化和查询异常仍安全停止。复制次数、剪贴板所有权与恢复边界不放宽。
- 浮窗流式内容从当前顶部锚点向下增长，并预留滚动条宽度。macOS 显式展示前核对原生尺寸、WebView 视口和屏幕比例，避免旧布局被当作新展示的就绪状态；超时不伪装成成功。

## 验收与安装

- Windows：`EchoLingo_0.2.4_windows_x64-setup.exe`；Apple 芯片 macOS：`EchoLingo_0.2.4_macos_arm64.dmg`。
- 使用标准双端构建与发布流程；只有必需 CI 和发布验收通过，才发布同次运行验证过的安装包。发布后不重新构建或覆盖 0.2.3 资产。
- 新增取词来源、剪贴板标记、放大镜连续性、隐藏 WebView 视口及浏览器展示回归。Windows 发布验收使用已确认嵌入实际应用的原生截图子程序，要求完整连续性用例结果；不能仅凭步骤退出成功认定通过。
- 更新前从托盘或菜单栏完整退出旧实例。安装来源、对应源码、SHA-256 和验证工作流见本次发布的清单与校验文件。
- Windows 未商业签名；macOS 使用 ad hoc 签名，未经 Apple 公证。系统可能显示安装风险或要求重新授权。

## 验证边界

这是内测版，不是稳定版。生成窗口、纯策略和浏览器 mock 测试不能证明所有真实应用均可取词，也不能替代物理鼠标跟随、复杂剪贴板历史、连续操作和混合 DPI 多显示器验收。原生几何与 WebView 视口确认不等于操作系统合成器已绘制清晰首帧；真实设备的流畅度、首帧清晰度及兼容性仍需复测，不作普遍时延或成功率承诺。
