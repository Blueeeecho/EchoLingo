# 0.2.2 内测版

本次统一发布 Windows x64 与 Apple 芯片 Mac 内测包，不替换已发布的 0.2.1。以下改进已经过自动化回归；真实应用、多屏和窗口操作手感仍请按验收清单复测。

## 更新内容

- 改进 macOS 浮窗连续拖动、原生窗口尺寸应用确认、样式切换时的位置锚点及拖边期间的布局协调；保留可调整尺寸的原生窗口框架。
- Windows/macOS 手动调整当前浮窗高度后优先保持用户高度，内容通过内部滚动访问；固定按钮不应重置高度，新一次翻译恢复内容适配。扩高时背景保持一致。
- 文件名等结构化非正文输入在适用条件下保持原样并明确提示；调整自动双向翻译与混合中文说明的方向处理，保留原始文本、复制内容和可见错误反馈。
- 翻译与 OCR 服务独立管理、推荐列表可折叠；优化凭据编辑、测试、开关、窄窗口焦点及空 OCR 提示。阅读正文行距统一收紧，仍保留代码与原始文本内容。
- 增加经文档核对的 Gemini、Groq、Ollama 预设，官方小牛翻译、Google Cloud NMT、彩云协议适配，以及需用户确认账号资格和模型的千帆、TokenHub、火山方舟试用引导。额度和资格以厂商当前控制台为准，不保证永久免费或每个账号可用。
- 默认仍只启用划词和截图两个快捷键；保留修改、清空及其他操作的自定义绑定。补充有界、无原文和密钥的诊断及完整回归覆盖。

## 下载与升级

- Windows：`EchoLingo_0.2.2_windows_x64-setup.exe`，Windows 10 1809+ / Windows 11。
- macOS：`EchoLingo_0.2.2_macos_arm64.dmg`，Apple 芯片 Mac、macOS 12+；Apple 系统翻译需要 macOS 26+ 和相应语言资源。
- 先从托盘或菜单栏完整退出旧实例，再安装或替换应用。macOS 如需重新确认辅助功能、屏幕录制权限，请核对授权条目对应当前安装的应用。
- `SHA256SUMS.txt` 和 `RELEASE-MANIFEST.json` 记录实际安装包哈希、源码提交及同一次发布验收记录。`EchoLingo-offline-engine-source.zip` 是 Windows 离线引擎对应源码，不是安装包；完整应用源码可从本页标签源码下载。
- 本版不覆盖旧版本资产。Windows 未商业签名；macOS 为 ad hoc 签名、未公证，请仅使用本仓库来源并核验哈希，不关闭系统安全保护。

## 已知限制与实机验收

**Windows 偶发 HTML 剪贴板格式恢复异常尚未定位根因。** 曾观察到原文取词正确但 HTML 格式读取为空；最新组合回归未复现，已增加仅测试环境启用的有界诊断。一次回归通过不代表该间歇问题已经根治。若遇富文本粘贴异常，请记录发生动作与应用版本，避免提交私密剪贴板内容。

macOS 原生几何、WebKit 顶部点击与输入回归已覆盖，但不能代替真实用户环境的首帧清晰度、连续拖动手感、混合 DPI／多屏及窗口外侧物理命中范围。合成边缘研究结果不确定，**不承诺窗口外扩 8px 热区已经验证**。请检查可见四边四角、松开后不回弹、缩小后可滚动、固定按钮及设置往返后的编辑输入。

第三方应用辅助功能支持和服务账号政策可能变化；真实微信、Codex 取词及各服务账号端到端调用仍需用户复测。不能可靠读取选区时可手动复制后使用“翻译剪贴板”，或截图识别。云服务会接收用户选择提交的内容；本机路径与云服务应由用户明确选择。
