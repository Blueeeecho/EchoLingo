# EchoLingo 0.2.8 内测版

- 截图编辑支持再次调整选区，并补充画笔、高亮、椭圆与局部笔画擦除；工具分组保留确认、取消和保存操作。
- 截图可固定为独立贴图窗口，便于对照查看；补充贴图生命周期、输入与显示边界测试。
- 支持原位文字与带背景备注、连续编号和编号箭头；标注可选中、移动、删除及撤销重做。
- 加强设置与历史文件的原子写入，避免共享临时文件碰撞和符号链接误写。
- 修复连续修改主题时，较早的保存完成后覆盖后续选择的问题。
- macOS 系统翻译区分系统报告的资源安装状态与实际语言对运行结果；遇到资源不可用时允许用户显式重新准备，避免新请求或过时回调错误清除恢复状态，不自动下载或重试。
- 加强截图编辑回归与安装包静态检查，保留失败证据；修复 macOS 自有许可确认和 Windows 安装包标记校验。

本版本使用当前源码重新构建 Windows 安装包和 macOS App/DMG，发布须通过完整回归及既有安装验收；不以历史语言补丁或旧安装包验收替代。发布清单与校验和绑定本次源码提交、验证运行和实际安装包字节。

内测版仍可能存在问题。Apple 翻译资源不可用的框架底层原因及具体设备恢复效果仍需实际设备验证。macOS 的签名、公证及权限要求以实际安装包和系统提示为准；不宣称新增 Apple 公证或所有真实应用场景均已验证。云翻译和 OCR 仅在用户自行配置启用后使用，相关服务费用由服务商收取。
