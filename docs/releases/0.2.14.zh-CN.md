# EchoLingo 0.2.14 内测版

## 下载

- **Windows 推荐免安装 ZIP**：下载 `EchoLingo_0.2.14_windows_x64-unpack.zip`，完整解压后打开 `Start-EchoLingo.cmd`。保留 NSIS 安装版，适合希望使用安装流程的用户。
- **macOS Apple 芯片**：下载 `EchoLingo_0.2.14_macos_arm64.dmg`。
- 升级前完整退出旧版；请核对 `SHA256SUMS.txt`，不要把 GitHub 自动生成的源码 ZIP 当作应用。

## 本次变化

- 设置页及服务管理文字更清晰，说明和注册链接使用蓝色下划线；窄窗口重新排版，快捷键录制反馈保持在当前操作行。
- 修复从历史重新打开翻译后，历史条目的语言选择影响下一次捕获或清空的问题。明确手动修改的语言仍保留。
- 请求诊断区分请求语言与最终解析语言，不记录原文。此项修正不代表所有现场自动翻译问题的根因已确认。
- Windows 增加解压即用的完整 ZIP，包含程序、中英离线引擎、双向模型及原始许可。修复冷启动期间第二次启动请求过早访问应用状态的问题。

## 运行要求与数据

Windows 10 1809+ / Windows 11 x64，仍需系统中的 Microsoft Edge WebView2 Runtime。启动器只检查运行环境，不自动下载或安装、不修改安全策略；缺失时请按提示前往 Microsoft 官方渠道安装。

免安装仅指应用文件无需运行安装向导。配置、历史与 WebView 数据仍保存在当前 Windows 用户的 AppData，密钥仍在 Windows 凭据库中，不会随 ZIP 搬走。ZIP 内不包含用户数据或凭据。

macOS 安装包面向 Apple 芯片、macOS 12+；Apple 系统翻译需要 macOS 26+。Windows 未商业签名，macOS 使用 ad hoc 签名且未 Apple 公证。旧版 0.2.13 保留下载。

## 验证范围

本发布要求同一提交的双端全新构建及安装包结构、版本、应用字节检查，Windows 最终 ZIP 的真实解压启动、设置 WebView、第二次启动转发、双向离线模型执行和内嵌捕获自检，以及实际设置快捷键和生成内容的原生焦点回归。发布清单绑定源提交、当前构建任务、文件大小及 SHA-256。

安装包的静态检查不等同于安装后完整运行验收；Windows ZIP 的测试不替代 macOS 现场运行、真实缺少 WebView2 的安装场景、物理多屏/混合 DPI、截图/OCR全量现场验证或断网证明。用户报告的现场翻译问题仍按具体复现结果判断。本版为内测预发布，不使用稳定版 Latest 标记。
