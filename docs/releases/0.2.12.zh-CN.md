# EchoLingo 0.2.12 内测版

- 调整 macOS Alt+S 截图取字的窗口排除规则：允许当前存活、图像已就绪的桌面贴图进入捕获画面，便于对贴图中的文字进行 OCR。
- 截图工具栏、选区及其他辅助窗口仍从捕获中排除；贴图是否可捕获继续核验窗口身份与生命周期，不将过期或未就绪的窗口当作有效贴图。

本版本使用当前源码重新构建 Windows 安装包和 macOS App/DMG，发布须通过既有回归及安装验收。发布清单与校验和绑定本次源码提交、验证运行和实际安装包字节，不以旧版资产或历史诊断替代。

新增合成验证的生成贴图捕获与 Vision OCR 步骤已在 macOS 运行通过；首轮合成测试尾部曾出现一次尚未定位原因的失败，后续诊断轮通过，不将诊断通过视为该次失败的根因已解决。合成测试不代表所有真实桌面、显示器及贴图生命周期场景均已验证。

本次不修改取词恢复或 Apple 系统翻译功能，也不宣称解决其既有现场问题。macOS 签名、公证及权限要求以实际安装包和系统提示为准。
