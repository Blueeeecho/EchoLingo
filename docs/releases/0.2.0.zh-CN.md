# 0.2.0 内测版

EchoLingo · 回声译 0.2.0 内测版，面向 Windows x64 与 Apple 芯片 Mac。

## 本次更新

- 改进截图框选放大镜与浮窗内容自适应高度，让选区定位和长译文阅读更方便。
- 新增免费服务配置向导，提供按平台组合的本地或免费额度服务建议及配置提示；需要第三方账号的服务仍由用户自行开通。
- 新增免费版本检查：可手动检查，或自行开启每日后台检查；默认不自动联网，只打开官方发布页，不自动下载或安装更新。
- 修复快捷键暂停、恢复和保存设置之间的时序冲突，避免旧操作覆盖最新配置。
- 改进快捷键冲突提示，以及 Windows 空白浮窗的输入焦点处理。
- 单个翻译服务重试时使用最新服务配置，避免旧配置和过期结果覆盖当前操作。
- 优化历史记录加载、单服务重试和快捷键恢复路径，减少重复读取与无关工作。

## 下载与升级

- Windows：下载 `EchoLingo_0.2.0_windows_x64-setup.exe`，适用于 Windows 10 1809+ / Windows 11。
- macOS：下载 `EchoLingo_0.2.0_macos_arm64.dmg`，适用于 Apple 芯片 Mac、macOS 12+；Apple 系统翻译需要 macOS 26+。
- 升级前请从托盘或菜单栏完整退出旧版。源码 ZIP 不是安装包。
- 文件校验值见 `SHA256SUMS.txt`；`RELEASE-MANIFEST.json` 记录对应源码提交、验证工作流及安装包哈希。Windows 离线引擎对应源码随本页附带。

## 验证与已知限制

安装包来自同一次完整 CI 构建，并在该次 Windows、macOS 和隔离前端回归全部通过后发布；不在验收后重新构建安装包。Windows 包还需通过真实安装与离线模型验收、精确安装包哈希核对。

这是内测预发布版本，不是稳定版。Windows 未商业签名；macOS 使用 ad hoc 签名，未经过 Apple 公证，系统可能提示风险或要求重新授权。自动化验收不等于所有真实供应商账号、输入法、目标应用和多屏配置均已验证。请仅安装来自本仓库发布页且校验值相符的文件。
