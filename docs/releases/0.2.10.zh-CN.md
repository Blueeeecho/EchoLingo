# EchoLingo 0.2.10 内测版

- 修复 macOS 截图选区窗口与目标显示器的绑定，改善多显示器上的选区定位。
- 保持实时截图选区透明，并修复首次显示和原地点击时的画面稳定性问题。
- 加强 macOS 只读取词恢复：遇到已明确识别的可选选区属性失败时，继续检查经过验证的祖先分组；仍需满足选区、窗口、焦点及安全边界，不以模拟复制兜底。

本版本使用当前源码重新构建 Windows 安装包和 macOS App/DMG，发布须通过既有回归及安装验收。发布清单与校验和绑定本次源码提交、验证运行和实际安装包字节，不以旧版资产或历史诊断替代。

内测版仍可能存在问题；合成测试不代表所有设备和应用场景均已验证。本次不修改 Apple 系统翻译功能，也不宣称已解决其资源或翻译可用性问题。macOS 签名、公证及权限要求以实际安装包和系统提示为准。
