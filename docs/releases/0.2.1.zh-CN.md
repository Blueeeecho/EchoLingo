# 0.2.1 内测版

EchoLingo · 回声译 0.2.1 内测修复版，面向 Windows x64 与 Apple 芯片 Mac。

## 本次更新

- 改进 macOS 选区读取：先在明确边界内读取可验证的选中文字；辅助功能接口不完整时，符合条件的显式取词可在复核原应用、窗口、安全输入状态与任务有效性后，向原应用发送一次受控复制。已知密码输入、空编辑器、窗口切换或不明确的选区仍会停止；无法安全完成时提供翻译剪贴板或截图识别提示。
- 改进 macOS 浮窗拖动：点击不再立即启动拖动；超过移动阈值后才开始，并保持按下位置的锚点。释放鼠标、切换任务或窗口状态后，过期的拖动不能继续移动窗口。
- 改进浮窗交付与显示反馈，区分实际显示成功、失败和被新操作取消；补充不含选中文字的显示链路诊断。
- Windows 复制快捷键发出后剪贴板没有更新，不再被误判为“没有选中文字”并静默处理；提供可操作的提示及有界诊断。不会延长等待、反复发送复制键或覆盖其他应用更新的剪贴板。
- 快捷键诊断反映当前登记状态，已恢复或已移除的绑定不再残留启动时的冲突警告；冲突提示不再未经确认就指认其他程序。

- 系统翻译准备提示显示实际语言对，支持的语言对不再被界面短列表误改；增加不含原文、译文或凭据的最近翻译阶段与错误分类诊断，并改进取消后的会话清理等待。语言资源未安装仍需在系统提示中完成准备。
- 本机自动双向翻译对符合严格格式的中英混合技术日志，仅翻译可识别的中文短句并保留英文、字段、数字和符号；手选语言与云服务不受影响。候选不明确时沿用普通翻译，详见 [范围说明](../mixed-local-translation.zh-CN.md)。
- 缩小 Windows 与 macOS 译文段落之间的视觉空行，保留单换行、列表和代码缩进；原始译文、复制与历史记录内容不变。

## 下载与升级

- Windows：`EchoLingo_0.2.1_windows_x64-setup.exe`，适用于 Windows 10 1809+ / Windows 11。
- macOS：`EchoLingo_0.2.1_macos_arm64.dmg`，适用于 Apple 芯片 Mac、macOS 12+；Apple 系统翻译需要 macOS 26+。
- 升级前请从托盘或菜单栏完整退出旧版。源码 ZIP 不是安装包。
- 校验值见 `SHA256SUMS.txt`；`RELEASE-MANIFEST.json` 记录源码提交、验证工作流及安装包哈希。Windows 离线引擎对应源码随本页附带。

## 验证与已知限制

发布流程要求同一次完整 CI 的 Windows、macOS 和前端回归通过，并直接发布该次验收的安装包，不在验收后重新构建。Windows 包另需通过真实安装与离线模型验收、精确安装包哈希核对。

应用的辅助功能支持可能随版本、焦点区域和系统状态变化。本版不保证所有 Codex、微信或其他应用区域均可自动取词；无法读取可信选区时请先手动复制，再选择“翻译剪贴板”，或使用截图识别。Windows 剪贴板未响应的提示修正不代表所有目标应用的模拟复制兼容性都已解决。自动化回归不替代用户真实应用、多屏和输入法环境的复测。

macOS 的紫色屏幕捕获图标是系统隐私提示，截图识别可能触发；这本身不是故障，也不能仅凭该图标判断是否上传屏幕。默认 OCR 在本机完成，选择云端 OCR 时以应用的明确配置及提示为准。

Windows 未商业签名；macOS 使用 ad hoc 签名、未经过 Apple 公证。本版本仍为内测预发布版。请仅安装来自本仓库发布页且校验值相符的文件。
