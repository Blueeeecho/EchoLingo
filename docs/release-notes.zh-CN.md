# EchoLingo 0.1.0 预览版

独立桌面翻译工具，Windows 优先，支持 Apple Silicon macOS。默认常驻托盘/菜单栏，按需显示浮窗。

## 使用

- Alt+D：划词翻译；没有选区时显示空白浮窗，不激活应用或聚焦输入框。
- Alt+S：框选屏幕，OCR 后直接翻译；Alt+Shift+S 仅识字，Alt+C 静默识字到剪贴板。
- 浮窗默认置于普通窗口上方，点击外部隐藏；钉住后保留，不设默认倒计时。
- Enter 翻译、Shift+Enter 换行；输入法确认候选词时不提交。翻译中可点原按钮停止，编辑/清空/隐藏也会取消旧翻译并阻止其写历史。
- 在设置中填写自己的供应商凭据。支持多家翻译结果对照、历史与收藏、深浅主题和自定义快捷键。
- 翻译：OpenAI 兼容、DeepSeek、智谱、硅基流动、通义千问预设，以及 DeepL、LibreTranslate。
- DeepL 与 LibreTranslate 分别传递简体/繁体目标；自建 LibreTranslate 需安装相应语言模型。服务拒绝目标时明确提示，不自动改成另一种中文。
- OCR：默认系统离线识别；可配置百度、腾讯、兼容视觉模型或高级 JSON 网关。选择云端 OCR 后，主动框选的截图会上传至所选服务。

保存配置不会自动测试。测试翻译发送 Hello，测试 OCR 上传应用生成的小图，可能消耗供应商额度；不附赠 API 密钥或额度。密钥保存在系统凭据库，绑定协议与服务域名。

## 安装与验证范围

Windows 安装包面向 Windows 10 1809+ / Windows 11 x64，使用系统 WebView2 和 OCR 语言包。macOS 安装包面向 macOS 12+ Apple Silicon；取词/截图需要系统授权。与其他翻译软件同时运行时，请避免快捷键冲突。

自动验证覆盖 Rust/前端单测、真实本地 HTTP 协议请求、腾讯公开签名向量、两平台 OCR 生成图，以及 Windows 临时测试窗口的选区、空选区、复制回退与剪贴板格式恢复。真实供应商账户、交互框选、多显示器、混合 DPI、各目标应用及安装卸载仍需按测试计划验收。

此版未完成商业签名或 Apple 公证；系统可能提示来源未验证。未提供商店上架或自动更新。完整记录见 [验证报告](test-report.md)。

macOS 本机建议使用固定的 `~/Applications/EchoLingo.app`。开发目录中的调试版、构建版和历史预览产物不需要同时启动；[本地安装工具](local-preview.zh-CN.md)提供签名验证、备份回滚与受限性能采样。静态原生代码使用应用自身的权限身份；临时签名重建仍可能导致系统要求重新授权。
