# 原地截图与图片编辑

默认 **F1** 选择可见窗口或拖选区域，松开后在原位置显示已捕获的选区像素和浮动工具栏，
不另弹一个获得焦点的普通编辑窗口。选区外是透明宿主上的暗色遮罩，并非整屏冻结图像；
选区内的编辑与导出使用已捕获图片，不会重新读取其下方应用。

F1 不调用 OCR、翻译、云服务或翻译历史，工具栏没有 OCR 按钮。
**Alt+S 无感 OCR 流程不变**（保留已有窗口悬停轮廓提示）。快捷键仍可修改或清空。

工具栏优先放在选区下方；底部空间不足时翻到上方。左右位置限制在选区所属显示器内，
不落进多屏间隙；上下都放不下时允许受边界约束的重叠。窄屏工具组换行，完成/取消/下载
操作置前并保持可点击；工具选项、尺寸提示和状态信息也按实际布局重新定位。

## 完成、取消与保存

- 初始是选择工具，不会因点击图片意外画出标注。可选择矩形、箭头、多行文字、
  像素马赛克、实心遮挡或裁剪，并撤销/重做。
- **✓ / Enter**：复制合并后的最终图片；复制成功才退出。截图完成时**不会自动复制原图**。
- **× / Esc**：直接丢弃本次未保存截图并退出，不修改剪贴板，不删除或改写任何已有文件。
  活跃绘制手势先取消手势；文字框和输入法先处理自己的 Enter/Esc。
- **↓ / Ctrl/Command S**：保存到设置中的系统桌面或自定义目录；采用截图时间命名的 PNG，
  重名添加编号，绝不覆盖已有文件。保存成功才退出；保存失败或取消时保留编辑。
  原位模式不打开「另存为」系统窗口；Ctrl/Command Shift S 提示到设置修改保存目录。
- 复制失败也保留图片和编辑，允许重试。导出进行中禁用重复完成/取消，避免取消与写入竞态。
- 裁剪修改实际像素尺寸，并保留裁剪区域的屏幕位置；导出不包含被裁掉的像素。
  Retina/DPR 只影响显示映射，不改变输出像素。
- Ctrl/Command Z 撤销，Shift Ctrl/Command Z 或 Ctrl/Command Y 重做。
  文字框中 Enter 换行、Ctrl/Command Enter 添加；中文输入法组合期间不会完成截图。
  仅明确进入文字标注时请求原生文本焦点。

### 本地图片仍使用普通编辑模式

「打开图片」打开本地 PNG/JPEG 后仍使用普通编辑窗口，保留缩放、适合窗口、复制、保存、
另存为及未保存关闭确认。复制/保存不自动关闭该模式。编辑不会写回源文件；取消文件选择
保留当前文档。再次截图会替换当前会话；未保存编辑不进入设置或历史。

## 原生宿主边界

macOS 使用不激活应用的 **NSPanel** 宿主复用同一 WKWebView；不把普通 NSWindow 的
collection behavior 当作全屏旁挂能力。显式文字输入请求焦点，初次呈现不抢占前台应用。
Windows 在当前 Rust 截图子进程结束后，由父应用的原位 overlay 承接编辑，使用不激活
呈现和会话限定的 Enter/Esc 转发；并非保留原截图子进程的窗口。

锁定依赖 Tauri **2.12.5** / Wry **0.57.1** 的透明 WebView 实现内部使用
`drawsBackground`。项目显式启用 `macos-private-api` 兼容特性，目标是直接分发 DMG，
**不宣称符合 Mac App Store 审核要求**。透明呈现和全屏空间行为仍须原生验证。

## 隐私与资源边界

编辑器内保留不可变原图和有类型的操作，允许最近 100 步撤销；单张图片最多
500 次编辑，文字单次最多 2000 字。大图还有限制单次重绘工作量的像素预算；较早达到
预算时会提示保存，再打开保存结果继续编辑，避免大量大范围马赛克导致界面长时间卡住。
输入图片最多 3200 万像素、单边 16384 像素、编码文件 32 MiB；不符合限制或损坏的
图片显示错误，不创建大画布。原生截图模块可以使用更严格的输入大小限制。

马赛克会重写像素，不是 CSS 模糊效果，但像素化不保证敏感文字不可推断。
**敏感内容推荐使用实心遮挡**。导出的 PNG 只有合并后的像素，不含原图、可恢复的
编辑图层、裁剪外部像素或源文件元数据；后端再次解码并重新编码。
保存/复制前会核验当前会话，旧截图的异步导出不能覆盖新截图。

WebView 不使用通用文件系统权限。打开文件、选择目录、保存与复制仅通过各自的
窄范围原生命令完成。图片不会进入 localStorage、设置 JSON 或翻译历史。

## 验证

```sh
npm run check
npm test
npm run build
npm run dev
# 另一个终端；需要获准的 Playwright Chromium 环境
npm run test:ui
# macOS 原生宿主夹具（不等于实机全屏/IME 验收）
bash tests/macos-screenshot-overlay-host-fixture.sh
```

`src/screenshot-model.test.ts` 检查像素坐标、裁剪、不可变操作、历史边界和输入限制。
`tests/screenshot-editor.mjs` 使用真实 Canvas 和假 IPC 覆盖普通模式与原位模式：DPR 1/2、
工具/撤销、裁剪位置、工具栏视口边界、最终图片复制、失败/取消保留、×/Esc 不写文件或
剪贴板、过期会话键事件和中文组合输入。浏览器测试不验证真实操作系统输入法或剪贴板。

macOS 宿主夹具检查实际 NSPanel 与共享 WKWebView 的宿主关系、呈现及清理；结果只适用于
该夹具覆盖面，不能据此声称已完成任意第三方全屏应用、Spaces、多显示器或真实中文 IME 验收。
Windows 的 `tests/windows-application-smoke.ps1 -ScreenshotEditorTests` 是既有实际应用
检查入口；旧版独立编辑窗口断言不能直接当作 0.2.6 原位流程已通过的证据。

发布前须针对最终集成提交在两端验证：真实 F1、点击窗口/拖选、Esc、悬停轮廓、原位位置、
权限、多屏缩放、全屏前台不退出、文本输入焦点、系统图片剪贴板、实际目录保存/重名不覆盖、
取消不变更文件/剪贴板及 Alt+S 无回归。原生夹具、浏览器假 IPC 和实机验收分别报告，
不得互相替代；不在文档中预先宣称测试已通过。
