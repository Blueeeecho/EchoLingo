# 独立截图与图片编辑

默认快捷键 **F1** 打开独立截图入口，和 **Alt+S 无感 OCR** 相互独立。
截图可选择可见窗口或拖选区域，随后进入独立图片编辑窗口。截图编辑不会调用
OCR、翻译、云服务或翻译历史。快捷键可以修改或清空；已有用户绑定不会被覆盖。

## 编辑与保存

- 矩形、箭头、多行文字（支持中文输入法）、像素马赛克、实心遮挡、裁剪。
- 裁剪修改实际图片尺寸，不只是隐藏画布外部的部分；撤销可恢复。
- 放大、缩小和适合窗口只影响显示。编辑和导出始终使用图片像素坐标，
  不因显示器缩放、Retina 或窗口大小改变。
- Ctrl/Command Z 撤销，Shift Ctrl/Command Z 或 Ctrl/Command Y 重做。
  文字框中 Enter 换行，Ctrl/Command Enter 添加；输入法组合中不会提交文字。
- 「复制」复制合并后的图片；「保存」保存到系统桌面，或者设置中选择的目录；
  「另存为」每次打开原生文件对话框。保存取消、文件对话框取消不会清空当前编辑。
- 打开本地 PNG / JPEG 后，编辑不会自动写回源文件。导出为新的 PNG；文件名由
  后端根据截图时间产生。若目标文件已存在，自动添加编号保存为新文件，不覆盖已有文件。
- **不会自动保存**。关闭未保存图片需要确认。再次请求截图会替换当前会话，
  未保存的编辑不进入文件、设置或历史。

## 隐私与资源边界

编辑器内保留不可变原图和有类型的操作，允许最近 100 步撤销；单张图片最多
500 次编辑，文字单次最多 2000 字。大图还有限制单次重绘工作量的像素预算；较早达到
预算时会提示保存，再打开保存结果继续编辑，避免大量大范围马赛克导致界面长时间卡住。
输入图片最多 3200 万像素、单边 16384 像素、编码文件 32 MiB；不符合限制或损坏的
图片显示错误，不创建大画布。原生截图模块可以使用更严格的输入大小限制。

马赛克会重写像素，不是 CSS 模糊效果，但像素化不保证敏感文字不可推断。
**敏感内容推荐使用实心遮挡**。导出的 PNG 只有合并后的像素，不含原图、可恢复的
编辑图层、裁剪外部像素或源文件元数据；后端再次解码并重新编码。
保存/复制前会核验当前会话，旧截图的异步导出不能覆盖新截图。

WebView 不使用通用文件系统权限。打开文件、选择目录、保存与复制仅通过各自的
窄范围原生命令完成。图片不会进入 localStorage、设置 JSON 或翻译历史。

## 验证

```sh
npm run check
npm test
npm run build
npm run dev
# 另一个终端；需要获准的 Playwright Chromium 环境
npm run test:ui
```

`src/screenshot-model.test.ts` 检查像素坐标、裁剪尺寸、不可变操作、历史边界、
马赛克像素覆盖、文本换行和图片限制。`tests/screenshot-editor.mjs` 使用真实 Canvas
和假 IPC 验证工具、DPR 1/2、中文组合输入、导出、取消、旧会话竞态、错误图片与零
OCR/网络调用，并输出浅色及窄窗口深色截图。

浏览器夹具不代替 Windows/macOS 原生验收：全局 F1、窗口悬停轮廓、点击窗口、
拖选、Esc、多屏坐标、权限、系统剪贴板、真实桌面目录和原生文件对话框仍须在各自
系统上检查。发布前需对最终集成提交运行全部检查。

### 实际 Windows 应用门禁

仅在隔离、已解锁的 GitHub-hosted Windows 桌面运行（脚本会强制检查）：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File tests/windows-application-smoke.ps1 `
  -ApplicationPath <本次构建或实际安装后的echolingo.exe> -ScreenshotEditorTests `
  -DefaultCapture -NativeCapturePath <本次构建的echolingo-native-capture.exe>
```

该模式不调用模拟 IPC：对生成窗口发送真实 F1，验证原生悬停轮廓、Esc 取消、拖选、
点击可见窗口、实际 WebView 的实心遮挡/裁剪、系统图片剪贴板、两次保存的真实 PNG
像素与不覆盖行为、原生 Open/Save As 取消、生成 PNG/JPEG 的原生打开成功与源文件保护、
独立编辑器失焦保持显示、未保存关闭的取消/确认。后端 OCR 调用
计数、回环 HTTP 连接计数和翻译历史均必须为零。文件只写入带所有权保护的临时目录，
不写桌面；测试结束清理自身进程和文件。`-InstalledPackage` 仅标记实际安装包测试，
调用方仍须提供安装后的真实可执行文件。浏览器夹具不能替代这一门禁。
