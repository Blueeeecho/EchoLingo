# EchoLingo 前端说明

前端使用原生 TypeScript、Vite 和 Tauri 2 API，没有 React、Web UI 组件库、外部字体或运行时 CDN。中文为默认界面，跟随系统深浅主题，支持手动切换，设置保存在桌面后端。

## 工作台

- 翻译工作台包含源/目标语言、原文编辑、多服务结果、逐项错误和请求耗时。没有内置伪造译文；仅展示后端真实结果。
- Ctrl/Cmd + Enter 发起翻译；Esc 在桌面版隐藏窗口。输入、更改语言、收到新选区会使进行中的旧请求失效，旧结果不会覆盖新内容。
- 截图翻译、剪贴板翻译、无感 OCR 通过后端命令启动。划词卡片说明如何在外部应用中选中并按全局快捷键，避免因点击应用窗口而丢失外部选区。
- 支持窗口置顶、复制译文，以及能力检测后的系统语音合成。系统语音可能通过网络处理文本，设置页作出说明。
- 单次最多 20,000 字符。

## 历史与收藏

历史由后端写入；前端不会复制一份持久化数据。支持原文/译文搜索、收藏过滤、收藏切换、单条删除和在翻译窗口重新打开。清空全部记录会显示明确的应用内确认对话框。

## 服务与偏好设置

服务字段与后端契约一致：id、name、kind、baseUrl、model、enabled、prompt。支持最多 12 个 OpenAI 兼容、DeepL、LibreTranslate 服务。OpenAI 提示词支持 `{source}` 与 `{target}`；原文由后端作为独立 user 消息传入。

API 密钥使用独立命令写入系统凭据库；不会从后端读回，也不会写入 HTML、历史、本地存储或日志。编辑服务时密钥字段始终为空，通过 hasKey 状态显示已保存。关闭对话框会清空输入框。连通性测试会发送 Hello，并可能消耗少量 API 额度，按钮提示及执行通知均说明此事。

提供五个全局快捷键、主题、保存历史开关、历史保留数量，以及系统权限诊断。API 地址使用 HTTPS，本机 localhost / 127.0.0.1 / ::1 服务允许 HTTP。拒绝地址内的用户名、密码、查询参数和片段。

## 浏览器预览

浏览器模式清楚显示“界面预览”，不请求翻译 API，不读取/保存密钥，不伪造译文或历史。主题、导航、输入、语言选择、设置表单与诊断界面可预览。全局快捷键、屏幕截图、OCR、安全凭据库和窗口操作要求桌面版。浏览器预览对服务保存明确提示桌面要求。

## 安全与无障碍

动态原文、译文、服务名称、服务错误、诊断结果和历史内容一律使用 `textContent` / `createTextNode` 输出；没有将 API 返回内容作为 HTML 渲染。图标来自固定的 SVG symbol。按钮提供名称，表单含标签，弹窗使用原生 dialog，支持键盘焦点与减少动画偏好。

## 验证范围

- `npm run check`：TypeScript 严格类型检查。
- `npm test`：前端模型测试，覆盖 API 地址隐私校验、不同服务模型要求、历史查询与收藏、文本原样处理和时间戳兼容。
- 真实截图、系统快捷键、OS 凭据库、翻译 API 与 Windows OCR 必须在对应桌面系统/服务凭据下验证；浏览器测试不等同于原生验证。
