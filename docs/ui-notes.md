# EchoLingo 前端说明

前端使用原生 TypeScript、Vite 和 Tauri 2 API，没有 React、Web UI 组件库、外部字体或运行时 CDN。中文为默认界面，跟随系统深浅主题，支持手动切换，设置保存在桌面后端。

## 工作台

- 翻译浮窗采用“上方原文 → 中间源/目标语言栏 → 下方多个服务结果”的垂直结构；顶部仅保留钉住、更多和关闭。次要操作收进更多，浮窗不显示品牌、应用导航、计数或教学卡，也没有系统标题栏。历史/设置为独立管理视图。
- 翻译浮窗包含源/目标语言、原文编辑、多服务结果及必要的逐项错误，不显示请求耗时。空白态只有输入区域、语言栏和可展开的轻量服务选择行。没有内置伪造译文；仅展示后端真实结果。
- 原文输入区 Enter 发起翻译，Shift+Enter 换行；兼容 Ctrl/Cmd+Enter，空输入不执行操作。中文/日文等输入法的组合状态、isComposing 和 keyCode 229 均不提交，长按 Enter 不重复调用。请求期间原翻译按钮变为停止按钮。编辑、更改语言、清空、隐藏或新捕获会中止旧翻译等待，不再写历史；展示 epoch 覆盖尚未分配编号就隐藏的情况。Esc 在桌面版隐藏窗口，输入法确认期间不处理全局快捷操作。
- 截图翻译、剪贴板翻译、无感 OCR 通过后端命令启动。划词翻译在其他应用中选中文字后按全局快捷键。空按 Alt+D 的 input 事件仅清空并显示浮窗，不请求输入焦点，也不自动调用 API；普通翻译与 OCR 事件同样不主动聚焦文本框。显式 Alt+A 入口可以聚焦输入。
- 支持窗口置顶、复制译文，以及能力检测后的系统语音合成。系统语音可能通过网络处理文本，设置页作出说明。
- 默认托盘静默启动，用户主动翻译时显示；默认关闭计时隐藏，由原生窗口逻辑在点击窗口外时隐藏。置顶后保持显示。
- 设置中可选择 3 / 5 / 8 / 12 / 20 秒空闲隐藏。仅新请求成功返回译文、当前为翻译视图且未置顶时计时；指针、键盘、滚轮和焦点交互会重置计时。编辑原文、新请求、切换历史/设置、打开弹层时取消。OCR-only 识别结果不启动计时，无感 OCR 不主动弹窗。
- 单次最多 20,000 字符。

## 历史与收藏

历史由后端写入；前端不会复制一份持久化数据。支持原文/译文搜索、收藏过滤、收藏切换、单条删除和在翻译窗口重新打开。清空全部记录会显示明确的应用内确认对话框。

## 服务与偏好设置

服务字段与后端契约一致：id、name、kind、baseUrl、model、enabled、prompt。支持最多 12 个 OpenAI 兼容、DeepL、LibreTranslate 服务。OpenAI 提示词支持 `{source}` 与 `{target}`；原文由后端作为独立 user 消息传入。

API 密钥使用独立命令写入系统凭据库；不会从后端读回，也不会写入 HTML、历史、本地存储或日志。编辑服务时密钥字段始终为空，通过 hasKey 状态显示已保存。关闭对话框会清空输入框。保存服务期间，表单、取消、关闭、Esc 和遮罩关闭均被锁定；请求完成或失败后恢复，避免旧请求修改或关闭新表单。连通性测试会发送 Hello，并可能消耗少量 API 额度，按钮提示及执行通知均说明此事。

提供五个可配置的全局快捷键（留空禁用对应快捷键，重复检查仅针对非空项）、主题、保存历史开关、历史保留数量，以及系统权限诊断。API 地址使用 HTTPS，本机 localhost / 127.0.0.1 / ::1 服务允许 HTTP。拒绝地址内的用户名、密码、查询参数和片段。

macOS 设置页单独显示辅助功能/屏幕录制状态，提供明确的授权、打开对应系统设置及刷新操作。进入设置、切回设置或刷新只检查状态；应用启动和快捷键不自动请求。空 Alt+D 即使未取得权限也只显示空白框，不显示旧权限 toast。真实 OCR/翻译失败与剪贴板恢复失败仍保留必要提示。

## 自定义 OCR API

`ocrProviders` 默认空列表，`activeOcrProviderId` 默认 `null`，即系统本机 OCR，不上传截图。添加云端服务不会自动启用；用户必须在“识别方式”中选择它。选中云端后，界面持续显示所选服务和截图上传端点，并在选择时提示。

OCR 服务独立于翻译服务，支持最多 12 个百度、腾讯、`openai-vision` 或 `http-json` 配置。百度/腾讯显示对应多字段凭据并使用原生认证；视觉模型填写 API 基础地址、模型、可选 OCR 提示词；JSON 网关填写完整请求地址、固定 JSON 请求模板和 JSON Pointer 响应路径。模板只替换字符串值中的 `{imageBase64}`、`{imageDataUrl}`，不执行 JavaScript；JSON Pointer 如 `/text`、`/data/text`，空路径可读取根字符串。认证 Header 与前缀可配置，`Bearer ` 的末尾空格保留，仅适用于兼容接口，不代替百度/腾讯认证。

OCR 密钥用 `set_ocr_api_key` / `delete_ocr_api_key` 独立写入系统凭据库；表单不读回已有密钥，关闭时清空输入，保存期间锁定表单和关闭操作。服务先保存，再保存密钥；失败会明确区分服务保存与凭据写入失败。删除当前 OCR 服务会切回本机模式。

`test_ocr_provider` 会上传程序生成的测试图片，并可能消耗 API 额度；测试按钮提示及执行通知均说明此事。浏览器预览不会保存真实 OCR 服务或调用接口。

## 浏览器预览

浏览器模式清楚显示“界面预览”，不请求翻译 API，不读取/保存密钥，不伪造译文或历史。主题、导航、输入、语言选择、设置表单与诊断界面可预览。全局快捷键、屏幕截图、OCR、安全凭据库和窗口操作要求桌面版。浏览器预览对服务保存明确提示桌面要求。

## 安全与无障碍

动态原文、译文、服务名称、服务错误、诊断结果和历史内容一律使用 `textContent` / `createTextNode` 输出；没有将 API 返回内容作为 HTML 渲染。图标来自固定的 SVG symbol。按钮提供名称，表单含标签，弹窗使用兼容 HTML overlay（焦点管理与 Esc 关闭），支持键盘焦点与减少动画偏好。

## 验证范围

本机桌面截图工具存在异常：CUA 对应用主界面的截图也可能全白，打开弹层后的辅助功能树也可能不完整。用户确认实际桌面主界面可见。现有证据无法将这些捕获异常归因为原生 dialog；保留普通 HTML overlay 作为兼容性改进，不能据此宣称已经证明或修复应用白屏。

默认 480px 桌面浮窗按内容适配高度，并受当前屏幕工作区限制；管理视图独立适配尺寸。原文、语言栏与译文在所有窗口宽度下保持上下顺序，宽窗口的设置卡片可使用双栏。浏览器交互检查覆盖导航、服务表单预览阻止保存、主题、诊断、历史空态、脚本文本不执行；布局夹具不能替代实际桌面焦点测试。

- `npm run check`：TypeScript 严格类型检查。
- `npm test`：前端模型测试，覆盖 API 地址隐私校验、不同服务模型要求、历史查询与收藏、文本原样处理和时间戳兼容。
- `node tests/frontend-interactions.mjs`：先启动 Vite 开发服务；通过隔离 IPC 测试桩验证保存中禁止取消/Esc/遮罩和重复提交、失败后恢复、空快捷键、非空重复拒绝、默认无计时、可选空闲计时交互重置及置顶抑制、OCR 配置/选择提示/密钥隔离/JSON 校验/删除回退，以及空选区不聚焦。该脚本不操作安装的 App，也不调用真实翻译或 OCR 服务；可用 `ECHOLINGO_TEST_CHROMIUM` 指定已安装 Chromium 路径。
- 真实截图、系统快捷键、OS 凭据库、翻译 API 与 Windows OCR 必须在对应桌面系统/服务凭据下验证；浏览器测试不等同于原生验证。
# 极简弹窗修订（2026-10-24）

用户明确要求快捷键翻译页只作为无感弹窗。现去除品牌/双语区标题/统计/教学/页脚，顶部仅钉住、更多与关闭；次要操作收进更多，复制/朗读在悬停或键盘焦点时显示。原文编辑框自适应至100px，长译文随窗口限高滚动。

原生捕获内容先整理换行和准备视图、适配大小，再无激活显示。默认按真实外部点击隐藏；管理视图不套用弹窗隐藏规则。手动输入/粘贴不整理，捕获原文可在更多中恢复。纯文本换行辨识与OCR几何段落均采用保守启发式。

420/520px 的短、中、长隔离样本无横向溢出；它们是布局夹具，不能当作真实供应商输出或原生焦点证明。下方保留此前设计记录供交接参考。
