# Windows 取词设置

选中文字后按 `Alt+D`，回声译会取得选文、显示浮窗并自动翻译。可在设置中更换快捷键。

## 默认快捷键与冲突

Windows 版在应用运行时优先处理默认的 `Alt+D`、`Alt+S`。它们使用原生输入拦截，避免普通全局快捷键注册冲突阻止使用；退出应用后恢复原用途。安装程序不永久锁定按键，系统安全桌面、权限边界和其他输入驱动仍可能限制拦截。

其他键盘组合使用系统注册。某一行不可用时会显示该行状态；修改其他快捷键或普通设置不会反复重试它。录制后松开所有按键即可自动保存并生效，失败时保留旧绑定；手动填写仍可使用保存按钮。

可选鼠标侧键：点击操作旁的“录制”，按下并松开后退侧键 `MouseX1` 或前进侧键 `MouseX2`。侧键仅在 Windows 支持，单独使用；未配置时保留鼠标原来的前进/后退功能。

## 取词方式

在“设置 → Windows 取词”中选择：

- **复制兼容**：默认方式。在原窗口仍有焦点时模拟一次 `Ctrl+C`，取得本次复制结果后尝试恢复原剪贴板。
- **严格识别**：优先使用 UI Automation 的真实选区信息，适合需要避免空选区复制整行的应用。

视觉上的选中高亮与应用提供的选区接口是两回事。部分编辑器在没有选文时按 `Ctrl+C` 会复制整行，此时可使用严格识别。无法安全保存剪贴板或确认复制来源时，取词会停止。

## 排查空白原文

1. 确认原应用能手动复制当前选文。
2. 检查快捷键是否被其他软件或原应用菜单占用。
3. 尝试复制兼容与严格识别两种方式。
4. 在“权限与诊断”中运行诊断，提交问题时附应用版本、Windows 版本和复现步骤。

应用的取词诊断只保留阶段、结果是否为空等数值，不记录原文、窗口标题、剪贴板文本或 API 凭据。提交其他截图或日志前，请自行检查其中是否含有个人内容。

## 剪贴板格式完整性

复制兼容模式在发送 `Ctrl+C` 前保存原剪贴板的全部格式。只有完整快照、来源核对和剪贴板代次检查成功，才允许派发复制；新复制、保护字段和恢复所有权边界保持有效。

Chromium 发布的 `WebKit Smart Paste Format` 是存在性标记。本实现仅在该精确格式的空值通过同代次原生只读检查后保留存在语义；原生错误或非空数据句柄不会被当成空标记。恢复使用包含单个 `0x00` 字节的独立流，非空标记保留原数据。其他未知空格式、不可读取的延迟格式和不能安全克隆的对象仍安全停止，不丢弃格式以换取成功。

诊断只使用有限数值表示快照阶段、格式类别、计数和失败类型，不输出实际格式名称、对象类型、异常文本或剪贴板内容。原生测试必须覆盖已知标记保留、未知格式拒绝及剪贴板恢复；静态测试不能代替实际 Windows 执行。
