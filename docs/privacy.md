# EchoLingo 隐私与数据流

版本：0.1.0 预览版，2026-10-25。

## 何时读取内容
- 用户触发选文翻译：只尝试读取当前应用选区。必要时模拟复制并恢复原剪贴板；不持续监听剪贴板。
- 用户触发截图：仅处理用户选定屏幕区域。默认本机系统 OCR，不上传图片；明确选择云端 OCR 后，该截图上传到所选供应商。
- 用户触发剪贴板翻译：读取当时的文本。静默 OCR 会将识别结果写入剪贴板。
- 没有遥测、用户账号、广告 SDK 或开发者服务器。

## 网络传输
翻译与连通性测试由 Rust 后端请求用户指定端点。文本和所需认证信息传给该服务；应用不能控制该服务的日志、保留政策和费用。云端 OCR 收到截图及其所需认证信息。百度、腾讯原生适配固定使用官方 HTTPS 目标；兼容视觉模型和 JSON 网关使用用户填写的地址。OCR 连通性测试只上传应用生成的中性测试图，不读取当前屏幕。

只允许远程 HTTPS，本机回环地址可使用 HTTP。重定向默认不跟随，以免把认证带到其他端点。响应限制为 2 MiB，超时 45 秒，不将供应商原始错误内容写入日志。

翻译中的停止按钮，以及编辑/清空原文、隐藏浮窗或开始新的捕获，会取消旧的翻译 HTTP 等待。已取消或已被新任务替换的翻译不能继续写入历史；完成时还会检查当前“保存历史”设置。清空全部历史会同时使此前的翻译任务失效，防止旧结果随后重新写入。取消无法撤回供应商已经收到的内容，也不保证供应商停止处理或免除费用。此处不将截图选择器或云 OCR 流程统称为可取消的翻译请求。

## 本地存储
- 密钥：macOS Keychain / Windows Credential Manager；不在配置、历史或前端持久存储中保存。双密钥与可选临时 Token 作为一份凭据保存。凭据绑定协议及端点 origin（协议、域名、端口）；更换供应商或协议后不会沿用旧密钥，需重新填写。修改同一服务的模型或路径可保留凭据。
- 设置：API 端点、模型、非秘密提示词、快捷键、语言与主题保存在 JSON。
- 历史：默认保留最多 200 条，并受约 8 MiB 总体积约束，可关闭/清除。原文和译文属于本机明文历史，使用共享电脑或处理敏感资料时应关闭。
- OCR 截图：随机临时路径，成功、失败与取消后清理；原生进程若被强制杀死或系统断电，仍可能有临时文件残留，应按系统临时文件规则清理。
- 原生桥接：macOS 原生代码静态链接到 EchoLingo 自身进程，不提取独立辅助程序；Windows 使用缓存中的 PowerShell/C# 系统 API 桥接脚本。无需管理员或额外 OCR 模型。

API 密钥删除按钮会删除系统凭据。卸载应用未必清理凭据库或应用数据；卸载前可先删除密钥和历史。不宣称自动安全擦除。

## 权限边界
macOS 的辅助功能和屏幕录制权限由系统授权；EchoLingo 不绕过权限。Windows 受保护窗口、管理员窗口或组织策略可能无法取词/截图，应用应提示使用替代入口。

快捷键和权限状态刷新只检查权限，不反复申请。macOS 的授权或系统设置入口仅由设置页的明确操作触发；未取得选区时 Alt+D 打开安静的空白框。临时签名预览在重建后可能需要重新授权，固定安装路径不能代替 Developer ID 签名。

不直接执行任意第三方脚本插件；自定义 API 和提示词不等于本机代码执行。译文和错误以纯文本显示，不执行供应商返回的 HTML/JavaScript。
